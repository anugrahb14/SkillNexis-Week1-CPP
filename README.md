# Skill Nexis - C++ Week 1

This repository contains the C++ programming assignments and mini project completed for Week 1 of the Skill Nexis C++ Programming Internship.

## Week 1 Assignments

### 1. Simple Calculator
A calculator program supporting:
- Addition
- Subtraction
- Multiplication
- Division

### 2. Sum and Average of Array Elements
A program that accepts array elements and calculates their sum and average.

### 3. Prime Number Checker
A program that checks whether a given number is prime or not.

### 4. Reverse a Number
A program that reverses the digits of a given number.

## Mini Project

### ATM Menu Program
A console-based ATM program supporting:
- Balance Check
- Deposit
- Withdraw
- Insufficient Balance Handling
- Exit

## Technologies Used

- C++
- Loops
- Arrays
- Conditional Statements
- Operators
- Switch Statements
- Console Input/Output

## Files

- `calculator.cpp` — Simple Calculator
- `array_sum_average.cpp` — Array Sum and Average
- `prime_checker.cpp` — Prime Number Checker
- `reverse_number.cpp` — Reverse a Number
- `atm_menu.cpp` — ATM Menu Mini Project
